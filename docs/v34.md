# V.34 — internal technical design

Authority: ITU-T V.34 (33 600 bit/s full-duplex with V.8 start-up). NOT
"V.32bis with a faster symbol rate".

Status: **DESIGN COMPLETE, DSP NOT IMPLEMENTED.** All numeric values below are
structural; exact tables/sequences must be extracted from the current V.34 text
(and SpanDSP `v34tx.c`/`v34rx.c`/`v34_tables.h`, `[REF]`) before coding.

## 1. Architecture

- Full-duplex on 2-wire, echo-cancelled, single band.
- Symbol rates: 2400, 2743, 2800, 3000, 3200, 3429 symbols/s (from `[REF]
  make_modem_filter.c`: V.34_2400 1600/1800 carrier, baud 2400; V.34_2743
  1646/1829; V.34_2800 1680/1867; V.34_3000 1800/2000; V.34_3200 and 3429
  similarly). Carrier ~1600-2000 Hz chosen after line probing.
- Rates: 2400..33600 in 2400 steps. Higher rates use multi-dim constellations
  (superconstellations), shell mapping, trellis-coded modulation; precoding/
  nonlinear encoding (L1/L2), shaped signal sets.

## 2. Start-up phases (V.34 §8)

1. **V.8 phase** — CI/CM/JM/CJ select V.34.
2. **Phase 1** — 1800 Hz INFO0a/b (and INFO0c for longer symbols) — capability.
3. **Phase 2** — line probing: 21 tone sets (600-3300 Hz) transmit "L1"/"L2"
   probing signals; receiver measures channel (gain/frequency response, SNR per
   band) and chooses symbol rate + carrier from the probed channel. Mandatory:
   do NOT assume 33600; channel decides.
4. **Phase 3** — INFO1a/b: selected rate + precoding + TX preamble info etc.
5. **Phase 4** — TRN training: equalizer + echo canceller convergence, sequence
   detection, PPH (phase recovery) for extended modes.
6. **Data mode** — with adaptive equalizer, carrier PLL, and idle signaling.
7. **Retrain** — phases 2-4 repeat as needed; V.34 has explicit retrain signals.

## 3. DSP elements needed

- 21-tone probe analysis + knob/frequency response interpolation.
- Multi-rate resampler (symbol rate not a divisor of 8000); fractional timing loop.
- Large fractional-spaced equalizer + adaptive echo canceller (NLMS), carrier PLL.
- Superconstellation decoder + trellis decoder (Viterbi), shell mapping/unmapping.
- TX: nonlinear precoder + shell mapper + trellis coder + shaping.
