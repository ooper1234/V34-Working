# V.32 / V.32bis — internal technical design

Authority: ITU-T V.32 (9600 bit/s, and fallback 4800 V.32), V.32bis (up to
14 400 bit/s). These are 2-wire **echo-cancelled** full-duplex QAM modems —
fundamentally different from V.22bis's FDM. NOT implemented via "V.22bis × N".

Status: **DESIGN COMPLETE, DSP NOT IMPLEMENTED YET.** All values below must be
re-verified against the current ITU-T text (spec §51) before coding.

## 1. Physical architecture

- One carrier band, 2400 symbols/s, carrier 1800 Hz.
- Full-duplex on 2 wires via adaptive echo cancellation (the local TX echoes into
  the RX band and must be removed), plus adaptive equalization.
- Modulation: QAM (V.32: 16-QAM at 9600, DPSK-style differential quadrant; V.32
  also defines 8-state trellis coding at 14400 V.32bis).

## 2. Rates and constellations (V.32 & V.32bis)

- V.32: 4800 bit/s (4-PAM? actually V.32 4800 = 16 "points" dual... confirm) and
  9600 bit/s 16-QAM with differential encoding on quadrant; 2400 symbols/s.
- V.32bis adds 7200, 12000, 14400 bit/s with trellis-coded modulation (V.32/QAM
  constellations, 4D TCM for ≥9600).
- Tones/sequences: AA (answer), AC (reserved / CCITT used), S1 (caller start),
  SB1 (answerer start), USB1 (unscrambled 1s), and the V.32 automode for V.22/
  V.22bis interworking (AAAAA... answer tone with on/off keying pattern per V.32
  automode, distinguishing V.32 caller vs V.22bis caller).

## 3. Echo cancellation requirement

Local TX at 1800 Hz band is suppressed in the RX path by an adaptive NLMS/LMS
echo canceller using the known TX symbol/signal reference. Convergence during
training (the S/TRN sequences). Diagnostics: ERLE + tap energy (spec §25).

## 4. Training sequences

V.32 uses S (37-symbol) / TRN (128-symbol) segments in a measured phase model:
IA, IB, II, III, IV, V per V.32 §2; V.32bis per its own annex. Exact probe
sequences are in the Recommendation and SpanDSP `v32bis.c` (which shares the V.17/
V.32bis constellation maps in `[REF]`). Timing values are NOT filled from memory
here.

## 5. Start-up answerer (summary)

```
answer call -> ANS/ANSam (2100/2225) -> wait caller
caller sends AA -> answerer sends AC ->  S/TRN exchange
-> equalizer + echo canceller converge -> data
```

Automatice: answerer listens for the caller's first real signal; V.32 automode
state machine decides V.32 vs V.22/V.22bis (via answering-tone modulation
differences) — never "energy => V.32".

## 6. Implementation plan (deferred)

- DSP: fractional-spaced complex LMS equalizer (reuse framework), NLMS echo
  canceller, 2400-symbol timing, carrier PLL, trellis coder/Viterbi decoder for
  the TCM paths, differential quadrant decoding.
- Interop target: any US Robotics / Lucent V.32 modem registered via ATA.

## 7. Open items to resolve from the Recommendation before coding

Exact S/TRN symbol patterns and durations; V.32 automode signal timing table;
trellis generator polynomials; constellation normalization; V.32bis rate-selection
sequence; retraining signal. Deferred to the gold phase.
